# 中通客服智助 · 浏览器插件安装教程

> 客服照着做，4 步装好，只需一次。

## 第 1 步：打开扩展管理页

打开 Chrome 浏览器，在**地址栏**输入：

```
chrome://extensions
```

按回车。

## 第 2 步：打开开发者模式

页面**右上角**有个「开发者模式」开关，点开它。

## 第 3 步：加载插件

1. 点左上角「**加载已解压的扩展程序**」按钮
2. 选择本文件夹（`extension` 目录）
3. 出现「中通客服智助·问题件桥接」卡片即装好

## 第 4 步：配置密钥（连接服务）

1. 在扩展管理页找到「中通客服智助·问题件桥接」
2. 点「**详情**」→「**扩展程序选项**」
3. 把管理员给你的**桥接密钥**粘贴进去，点「保存」
4. 显示「连接成功」即可

> 密钥在服务端电脑的 `zto-cs\config\bridge_secret.key` 文件里（记事本打开复制）。

## 装好后怎么用

**不用管它**——插件在后台自动工作：

- 你开着中通「新问题件查询」页面时，插件每分钟读一次列表报给服务
- 自动回复开着时，服务把回复话术准备好，插件**帮你填进回复弹窗**
- **最后一步（点提交）由你确认**——半自动模式默认如此

## 常见问题

**插件显示红色（未连接）？**
→ 检查服务是否启动（服务电脑双击 `启动服务.bat`），密钥是否粘贴正确。

**页面看不到插件工作？**
→ 确认你在中通「新问题件查询」页面（datahub-portlet.zto56.com），其它页面插件不工作。
